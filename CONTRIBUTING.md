# Contributing to Interview Skills

Thank you for your interest in contributing! This project is open-source and welcomes improvements from the community.

## Ways to Contribute

### Add or improve company profiles
The `references/company-profiles.md` file contains interview style descriptions, evaluation criteria, and process details for each supported company. If you have firsthand interview experience at a company not yet covered, or want to update an existing profile, a PR is very welcome.

### Add role-specific question frameworks
The `references/question-design.md` file covers question design principles per role (backend, product, data, etc.). If you have experience interviewing for a specific role and want to add or refine the framework, open a PR or issue.

### Fix documentation or translation errors
Typos, unclear wording, and translation improvements in `README.md` (Chinese) and `README-en.md` (English) are always welcome.

### Suggest new features or scenarios
Open an issue describing the scenario you want to practice (e.g., a new company, a new role, a specific interview format) and we will consider adding support for it.

## How to Submit a Pull Request

1. Fork the repository
2. Create a branch: `git checkout -b your-feature-name`
3. Make your changes
4. Commit with a clear message: `git commit -m "Add: company profile for XYZ"`
5. Push and open a PR against the `main` branch

## Good First Issues

If you are new to the project and looking for a starting point, look for issues labeled `good first issue`. These are typically documentation improvements, new company profiles, or small feature additions that do not require deep familiarity with the codebase.

## Questions

Open an issue or start a Discussion in the GitHub Discussions tab.
