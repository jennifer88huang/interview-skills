# 轻量级 UI 设计：AI 模拟面试官

这个文件夹存放 `interview-skills` 的轻量级产品 UI 原型。设计目标是让用户在一个页面里完成：

- 输入 JD：支持链接、粘贴文本、上传图片 / Word / PDF / TXT
- 输入简历：支持粘贴文本、上传图片 / Word / PDF / TXT
- 选择公司、岗位、面试轮次和训练模式
- 生成 AI 面试官模拟结果：匹配度分析、10 道面试题、追问方向、备战建议

## 文件说明

- `index.html`：可直接打开的静态原型页面
- `styles.css`：页面布局和视觉样式
- `app.js`：本地交互逻辑，模拟生成结果

## 使用方式

直接用浏览器打开 `index.html` 即可。当前版本是前端交互原型，不会上传文件，也不会调用真实模型接口。

## 设计原则

- 首屏就是工作台，不做营销落地页
- 信息密度适中，适合求职者反复使用
- JD 和简历并列输入，降低来回切换成本
- 输出区域拆成「匹配度」「面试题」「追问」「备战建议」，对应仓库现有 Skill 能力
- 文件输入先承载格式与状态，后续可接 OCR、PDF/Word 解析和真实 AI 接口
